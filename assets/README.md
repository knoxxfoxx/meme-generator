# Assets Folder

Place your meme template images in this folder.

## Supported Formats
- JPG/JPEG
- PNG
- GIF
- WebP

## How to Use

1. Add your template images to this folder
2. Update `templates.json` in this folder with your image filenames

Example templates.json:
```json
{
  "templates": [
    "meme-template-1.jpg",
    "meme-template-2.png",
    "funny-cat.jpg"
  ]
}
```

The templates will automatically appear in the left sidebar gallery when you click on them.
